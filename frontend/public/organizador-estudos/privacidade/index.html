Politica de Privacidade do Organizador de Estudos

Ultima atualizacao: 10/07/2026

O Organizador de Estudos nao vende dados pessoais, nao coleta senhas, nao coleta dados de pagamento e nao envia nenhum dado do usuario para servidores do EducaplayJA ou de terceiros.

1. O que e esta extensao

O Organizador de Estudos e uma extensao para Google Chrome que ajuda a organizar a preparacao para concursos publicos: cadastro de materias e topicos do edital, cronograma semanal, cronometro de foco (Pomodoro), registro de notas de simulados e um painel de progresso.

2. Dados tratados pela extensao

As materias, topicos, cronograma, configuracoes do cronometro e notas de simulados que o usuario cadastra sao usados exclusivamente para exibir e atualizar essas mesmas informacoes dentro do proprio aplicativo, no navegador do usuario.

3. Dados que nao coletamos

  • Nao coletamos senhas.
  • Nao coletamos dados de cartao, PIX ou pagamento.
  • Nao coletamos documentos pessoais.
  • Nao vendemos nem alugamos dados pessoais.
  • Nao usamos dados da extensao para publicidade comportamental.
  • Nao enviamos o conteudo de arquivos importados para nenhum servidor.

4. Armazenamento local

A extensao usa o armazenamento local do Chrome (chrome.storage.local) para salvar os dados cadastrados pelo usuario. Essas informacoes ficam apenas no navegador do proprio usuario, neste dispositivo, e podem ser removidas ao limpar os dados da extensao no Chrome ou ao desinstala-la.

5. Importacao de arquivos de uma pasta local

Ao usar a funcao "Importar da pasta", a extensao pede permissao do sistema operacional para ler o conteudo de uma pasta escolhida pelo usuario. Ela le apenas os nomes dos arquivos (PDF, Word, Excel, PowerPoint, video, audio, e-book, texto) para sugerir topicos, e guarda uma referencia local (no IndexedDB do navegador) para reabri-los depois. Nenhum arquivo, nem seu conteudo, e enviado para fora do navegador do usuario.

6. Permissoes usadas

  • storage: salva localmente, no navegador do usuario, os dados cadastrados no app (materias, cronograma, estatisticas do cronometro, simulados).

7. Recursos externos

A interface carrega uma folha de estilo de tipografia hospedada pelo Google Fonts, usada somente para exibir as fontes visuais do aplicativo. Esse carregamento nao e codigo executavel e nao envolve nenhum dado cadastrado pelo usuario, mas, como qualquer requisicao de rede, passa pelos servidores do Google.

8. Compartilhamento de dados

A extensao nao possui servidor proprio e nao envia dados cadastrados pelo usuario para o EducaplayJA ou para terceiros. Caso uma versao futura passe a incluir recursos como sincronizacao em nuvem, conta de usuario ou anuncios publicitarios, esta politica sera atualizada antes da ativacao desses recursos.

9. Seguranca

Recomendamos manter o Chrome atualizado e instalar a extensao somente pela Chrome Web Store oficial.

10. Alteracoes nesta politica

Podemos atualizar esta politica para refletir melhorias da extensao, exigencias da Chrome Web Store ou mudancas legais. A data de atualizacao sera alterada quando houver nova versao.
